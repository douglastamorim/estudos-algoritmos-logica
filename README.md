# Estudos de Algoritmos e Lógica de Programação

Repositório criado para registrar minha evolução nos estudos de
Algoritmos e Lógica de Programação durante minha formação em
Análise e Desenvolvimento de Sistemas (ADS).

## 📚 Sobre

Aqui estão reunidos exercícios desenvolvidos utilizando o
Visualg, com foco no desenvolvimento do raciocínio lógico e na
resolução de problemas através da programação.

## 🧠 Conteúdos praticados

- Variáveis e tipos de dados
- Entrada e saída de dados
- Operadores matemáticos
- Estruturas condicionais
- Estruturas de repetição
- Cálculos e operações matemáticas
- Vetores e sequências
- Resolução de problemas
- Desenvolvimento do raciocínio lógico

## 🛠️ Tecnologia utilizada

- Visualg
- Linguagem Portugol
